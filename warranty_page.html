🛡 ประกันอุปกรณ์
1) ลูกค้า (ชื่อ หรือ เบอร์โทร)
เจอ = เลือกลูกค้า · ไม่เจอ = กรอกชื่อ/เบอร์ด้านล่างแล้วระบบสร้างใหม่ตอนบันทึก
เบอร์จะจัดเป็น 0xx-xxx-xxxx อัตโนมัติ
2) อุปกรณ์ / ประกัน
เลือกจากรายการ = เติม ซื้อจาก / เบอร์ร้าน / ราคา / ปีประกัน ตามครั้งล่าสุด
วันหมด = วันซื้อ + ปีประกัน (แก้เองได้)
กดบันทึก → ทวนข้อมูล → ยืนยัน · ลงรายการถัดไปได้ต่อ
ทวนข้อมูลก่อนบันทึก

ตรวจชื่อลูกค้า / สินค้า / วันประกัน ให้ถูกต้อง แล้วกดยืนยัน
